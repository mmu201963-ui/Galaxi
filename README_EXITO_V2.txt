GALAXI EXITO V2

Cambios:
- Entrada MOVEMENT ONLY anticipatoria: velocidad + aceleracion + impulso lider de BTC.
- No espera a que el precio ya haya recorrido un movimiento grande.
- No usa IA, Top Trader, funding, OI ni anomaly threshold para decidir la entrada.
- Scanner mantiene el universo completo y trabaja aproximadamente cada segundo.
- MAX 12 posiciones: 6 LONG / 6 SHORT.
- El scanner no se congela por perdida de ciclo.
- Objetivo compuesto por ciclo: +5% sobre la base actual.
- Al alcanzar el objetivo: cierra todas las posiciones, recalcula equity y crea una nueva base/objetivo.
- El dashboard muestra Base -> Objetivo y las señales ANTICIPA LONG/SHORT.

Nota: anticipar movimiento no garantiza que el movimiento posterior ocurra ni que una operacion sea rentable.
